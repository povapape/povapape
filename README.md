# Привіт, я Матвій 👋

Розробляю вебсервіси, інженерні інструменти та автоматизацію бізнес-процесів.

## Проєкти

### Tarlex Engineering

Багатомовний сайт для промислової водопідготовки з каталогом, конфігуратором систем, кабінетом клієнта й адмін-панеллю. Окремий FastAPI backend обробляє замовлення та інтеграції з Firebase, Google Sheets і двома Telegram-ботами. Для API також підготував Cloudflare Worker із резервним маршрутом.

🌐 [Переглянути сайт](https://tarlux-engineering.com)

### МемброОблік

Внутрішній сервіс для обліку клієнтів, мембран і замовлень на очищення чи регенерацію. Інтерфейс побудований на React і Vite, сервер — на Express.

### CoreFlow

Візуальний редактор логіки PLC з робочим полотном, генерацією коду Structured Text і C++ та симуляцією логіки.
